# Water Drain：PC / 手机操作

两端共用 BeginScene、GameScene、角色数值、基因系统和存档格式，不需要维护两套场景。Android / iOS 运行时自动启用横屏触控；PC 默认保留键鼠。

PC 主菜单通过「操作指南」查看键鼠说明，可用 Esc 返回；设置、操作指南和退出游戏并排显示。

## 手机

- 左摇杆：移动。
- 点击场景：像 PC 鼠标一样，点击哪里就朝哪里射击；按住连续射击，拖动改变目标，松开停止。没有右侧攻击摇杆。移动摇杆和 UI 按钮上的触摸不会触发射击。
- 跳跃：按下起跳，按住保留原来的长按跳跃手感。
- 下落：从单向平台向下穿过；也可左摇杆向下 + 跳跃。
- 冲刺：沿当前移动 / 瞄准方向冲刺，按钮显示冷却。
- 附魔：依照基因链顺序激活属性，按钮显示状态。
- 交互：靠近冷库、基因终端或最终回流阀后可用。
- 右上角暂停：暂停、设置、重试或返回主菜单。
- 基因界面：点击槽位、点击库存装入；上下拖动库存列表；点击左右按钮交换位置，再点击确认装配。

暂停、切换场景、离开应用时清空触控按住状态；恢复后需要重新按下，不会自动连射。

手机主菜单的「操作指南」可查看六项触控说明；游戏中暂停后点击「操作」也可查看，关闭后仍保持暂停。主菜单不再常驻左下角操作文字。

手机从启动开始使用横屏，进入横屏后只允许左右横屏切换。Player Settings → Resolution and Presentation 的 Default Orientation 保持 Landscape Left，Portrait 和 Portrait Upside Down 禁用。修改后需要重新打包并覆盖安装，手机上已有的安装包不会随项目设置更新。

## Unity 编辑器预览

停止运行后，勾选 **Tools → TapGJ → Mobile → Touch Controls Preview (Next Play)**，再进入 Play。鼠标可检查单个触控控件；多指并行操作需要触屏或输入自动测试。取消勾选后，下次 Play 恢复 PC 操作。

建议在 Game 视图检查 16:9、较宽的手机横屏和 4:3 平板。运行时 UI 会缩放并避让屏幕安全区。

## 发布

这次不打包。发布 Android 时在 Build Profiles 安装并选择 Android 支持，场景仍使用现有两个场景；iOS 使用对应平台支持和 Xcode。手机上的实际帧率、系统返回、刘海与触控延迟仍需要目标设备实测。
