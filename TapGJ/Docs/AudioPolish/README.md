# 地漏：水与涌现音效

本地原创声音合成，未使用下载录音或在线付费生成服务。Unity 的 fal 音频服务没有配置密钥，因此本次没有调用云端音频模型。

31 个可独立编辑的 WAV，44.1 kHz、16-bit、单声道，总计约 1.65 MB。目录为 `Assets/Resources/Audio/WaterDrain`。保留原先安静的洞窟背景氛围，本次只制作和接入短音效。

## 试听

`WaterDrain-SFX-Preview.wav` 约 18.5 秒，依次为：三种水弹、落水、吸水、放水、空中踏跃、冲刺、播种、蒸汽、导电、生长、爆破、基因拾取、节点、反应接力、通关。

水声通过不同尺寸的衰减气泡共振、滤波水花噪声和细小滴落分层合成。短提示保持柔和，较大的反应加入低频与水花；没有使用长时间尖锐高频或突兀首尾。频谱和峰值分析见 Synthesis.json。合成脚本在 `Tools/make_water_audio.py`，可重新生成或调整。

## 音效与触发

| 文件名 | 触发 |
|---|---|
| water_shot_01—03 | 玩家实际武器发射，轮换变体 |
| water_impact_01—03 | 水弹实际接触场景或目标，寿命结束不误报撞击 |
| fire_shot / poison_shot | 当前火、毒属性的武器发射 |
| absorb / release | 成功吸取、释放身体蓄水；空水或失败操作不播放成功声 |
| jump / air_step / land / dash | 跳跃、泡泡踏跃、落地、八向冲刺 |
| seed / recall | 成功播种、回收；播种不会再被当成开枪 |
| steam / conduction / growth / explosion / fracture | 对应的共享元素反应 |
| heal | 恢复补给、Monster4 实际治疗或滋养脉冲 |
| gene / chest | 基因拾取、冷库开启 |
| hurt / death | 主角受伤、死亡 |
| node / chapter / resonance / victory | 节点完成、区域提示、三种反应接力、结算 |
| ui | 可交互按钮的鼠标或键盘操作 |

## 混音与生命周期

- 使用现有音效音量控制，与背景音乐音量分开。
- 短音效预加载为 PCM，减少触发延迟。导入音频资源不随场景音效对象销毁。
- 相同反应设置短间隔，最多 16 个受管理的音效同时播放，减少连锁时过度叠加。
- 世界反应按与玩家的距离衰减，22 米外不播放；暂停时抑制世界音效，按钮提示仍可用。
- 重试复用唯一音效服务，切换场景清理旧的短音效，监听器避免重复。
- 静音仍视为已处理，不会让冷库退回另一个未静音的播放源。

## 验证

编辑器：104 / 104，包括每个 WAV 的存在、格式、长度、采样、非静音、安全峰值、首尾和直流偏移。

运行时验证使用实际武器、碰撞、吸放水、跳跃、踏跃、冲刺、播种及回收；元素声音通过共享事件接口逐项验证接线。另检查 DSP 输出、远处反应过滤、同帧连锁限流、暂停、静音、结果面板与重试后的唯一服务/监听器。为隔离动作验证，临时暂停敌人并开启玩家无敌；测试后恢复设置和本机进度。详见 PlayMode.json。

运行时：30 / 30 通过，控制台无错误。测试中发现并修复主角落地后的播种检测起点过低问题；实际 R 播种及近墙阻挡均已验证。

编辑器初始开启了 `Mute Audio`。测试临时取消静音并预热音频采样缓冲，已读取到实际非静音输出；结束后恢复静音、原存档、结局记录、输入设备和音量，停止运行并打开 BeginScene。在 Unity 内试听时，需要关闭 Game 窗口的 Mute Audio。

程序分析与运行验证不能替代人耳对音色和响度的判断；试听文件用于继续调音。
