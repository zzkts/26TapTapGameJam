# 基因案子对齐与额外玩法清理

2026-10-16。依据用户提供的《Tap26GJ-核心玩法模块-基因.docx》（Downloads 版本）。本次收束之前额外加入的玩法，保留现有环境及基因战斗框架，没有打包游戏。

- F / S+F 主动吸取、携带、放出水量，以及污染、浮力和水体跳跃。
- Q/R/T 元素种子切换、播种、回收与回流能量。
- 额外空中踏跃、八向冲刺、湿润箱体推拉、蒸汽托举。
- 黏附、喷射、共生三种身体基因及其资源。
- 供水、菌群净化、动力计时、生态生长与堵管、跨区域水网联动。
- 压力、重量、生长、破壳、导电节点的任务、奖励及通关前置条件。
- 多反应共振奖励、反应发现手册、节点地图和额外试验模式入口。
- 冷库三选一界面；改为案子的两份随机基因散落、靠近拾取。
- 上述系统的旧构建器、测试工具和九个专用音效，避免之后重建世界时重新引入机制。

移出 Assets 的文件及原始 meta 在 [归档清单](../../AssetArchive/2026-10-16-gene-spec/manifest.json) 中，按原目录保存在该归档下。它们不会进入 Unity 的资源导入和编译。

## 保留与调整

- BeginScene 菜单和单张连续 GameScene，泵站、菌林、核心三个环境区域及自动消失的到达提示。
- 原有环境图像、管线、水池外观、菌群、晶体和平台；环境贴图文件没有修改。九个旧机关状态标记被移除，其它场景 SpriteRenderer 保留，354 → 345。
- 原有基础移动、跳跃、土狼时间、输入缓冲、水平冲刺、人物动画和水弹表现。
- 基因库存、独立实例、进化、终端内的装配草稿、确认／取消，以及属性右键轮换和 3 秒装填。通用数值和弹道框架保留，未代替策划扩写新的基因条目。
- 案子明确允许的环境电属性来源与战斗中的元素反应保留，移除反应对额外场景机关的耦合。
- Monster4 对其它敌人的治疗、已有敌人攻击表现、生命补给与检查点。
- 子弹和水花对象池、既有图集及 UI 防溢出处理。

主线现在是：**打怪／开冷库获取基因 → 在终端装配 → 依次探索三个环境 → 击败三名核心守卫 → 最右侧回流阀按 E 选择结局**。不再要求蓄放水、种植、供电或接通节点。

六个冷库放到基础移动可达的地面；核心准备终端位于 x=100，守卫区域从 x=112 触发。原净化池跨越平台与主路对齐，旧机关物体保留外观但移除阻挡碰撞和物理行为。高处敌人的掉落向下检测延长到 32 米，避免移除空中能力后基因悬空。

终端 A/D 选择槽位，Space 确认；原左右调整按钮仍用于调整基因排列。交互沿用 E，与案子第 8.3.3 节及现有控制一致。
