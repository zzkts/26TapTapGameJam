## 当前可玩闭环

开始游戏 → 探索与战斗 → 敌人死亡掉落 / 开启冷库 → 拾取基因 → 三份同类初级基因即时进化 → 在终端编辑草稿 → 确认装配 → 继续战斗。暂停、设置、死亡重试和返回主菜单已贯通。

| 输入 | 行为 |
| --- | --- |
| A / D | 移动，可与射击同时进行 |
| W / Space | 跳跃，支持离地宽限和落地预输入 |
| S + 跳跃 | 向下穿过单向平台 |
| 左键按住 | 持续射击，朝向光标 |
| 右键 | 激活当前属性基因 |
| 左 Shift | 冲刺，拾取模块解锁后可在地面或空中使用 |
| E | 与最近的可用终端、冷库、基因或模块交互 |
| Esc | 关闭当前编辑 / 设置页，或暂停、恢复游戏 |

回血补给同时支持接触拾取；满血时不消耗。所有交互都会验证范围及角色存活状态。

| 怪物 | 类型 | 行为与配置 |
| --- | --- | --- |
| Monster3 | 近战 | 地面巡逻、检测追击、接触伤害 |
| Monster4 | 支援 | 飞行巡逻、范围治疗、恢复动画与连接线，不伤害玩家 |
| Monster5 | 近战 | 地面巡逻、检测追击、接触伤害 |
| Monster6 | 远程 | 飞行巡逻、射击自己的子弹、危险范围内后退 |
| Monster7 | 远程 | 飞行巡逻、射击自己的子弹、危险范围内后退 |

所有新旧敌人均保留各自的头顶血条、受击反馈、死亡动画和掉落入口。新怪物根节点负责物理，`Visual` 子节点负责动画；已按角色统一动画帧的世界宽度，避免切换状态时突然变大或缩小。

巡逻现在会检测墙面和平台边缘，碰墙立即调整朝向、短暂停顿后向反方向移动；另有位移停滞检测作为兜底。地面法线不会误判为前方墙壁。远程敌人冷却就绪时先攻击，避免靠近玩家后只顾后退而不射击。

远程子弹使用扫掠检测，避免高速穿过薄墙；玩家无敌时不会受伤。受击会打断敌人待执行的攻击，死亡后停止物理和支援光环。

## 玩家修复

- 每个玩家持有独立 InputActionAsset，销毁时释放，不再共同启停同一个输入资源。
- 移动、空中操控和持续射击互不锁死；地面检测排除敌人和已忽略碰撞的平台。
- 修正碰撞体脚底偏移、枪口位置及纯 Sprite 动画绑定。
- 跳跃默认速度 4，离地宽限与预输入均为 0.1 秒。
- 冲刺默认未解锁，速度为移动速度的 1.5 倍，持续 0.2 秒，冷却 2 秒；结束后恢复重力和碰撞图层。
- 受击有击退、0.1 秒时停、0.8 秒无敌与闪烁；时停使用真实时间恢复，兼容暂停菜单。
- 生命值扣除、治疗上限、死亡信号、跌出地图及重试恢复已统一处理。
- 补齐 `EnemyBullet`、`PlayerInvulnerable`、`Pickup`、`OneWayPlatform` 图层，并修正敌人与 Default 地形被禁用的碰撞关系。

## 基因与元素

`Modifier` 是原始配置，运行时库存克隆为独立实例。三份初级基因合成一个高级实例，之后的同类掉落开始积累新实例。同一实例不可占两个槽，不同同名实例可以重复装备，进化不修改原始资源。

终端编辑只修改草稿，支持装入、替换、移除和换位。确认后更新战斗数据并重置属性队列；取消不提交。无终端不能打开编辑器。

改造基因按槽位顺序常驻结算；属性按槽位顺序提取。右键开启当前阶段，结束后下一属性等待再次激活，最后一个结束后统一重载 3 秒。无属性时不启动重载。普通射击和常驻改造在重载期间仍然有效。

每次射击保留独立快照。后续进化、重新装配或属性切换不影响飞行中的子弹。分裂继承快照与父弹已命中的目标，避免生成后立即重复伤害同一目标；默认只分裂一代，每次射击共享 24 枚总生成预算。

已接入扩散、火种、初级命中涡流、高级随弹涡流、毒雾、穿透、反弹、分裂及既有数值改造。火每秒扣最大生命值的 5%，毒每秒基础伤害 1；毒抗性 100% 时免疫，超过 100% 转为治疗。电来自环境，不能装配为基因；湿润目标及水域参与导电。火毒爆炸处理已去重，火水生成蒸汽并清除燃烧。

## UGUI 与 Shader

UI 沿用 `BasePanel` / `UIManager`，未引入另一套 UI 框架。新美术用于书本、基因槽、分类图标、描述区、星标与世界交互物。编辑页有分类、滚动库存、进化进度、实际属性顺位和确认 / 取消。

HUD 显示生命、冲刺状态、装配槽、当前属性、阶段 / 重载进度及获取反馈。修正了 Filled Image 未绑定 Sprite 导致血条始终满格的问题。暂停与设置页在 `timeScale = 0` 时仍可淡入淡出；设置关闭不会恢复底层暂停。主菜单保留原背景和按钮，默认显示主界面而非对话测试画面。

`Assets/ArtRes/Shader/Combat/ElementSprite.shader` 提供水、火、毒流动表现、电弧、区域淡出和受击白闪。角色与子弹通过各自的 MaterialPropertyBlock 设置参数，不相互污染共享材质。子弹复用现有 WaterVfx 的拖尾及撞击水花。

未定配置采用可调整默认值，例如槽数 6、附魔阶段 4 秒、新怪物血量及部分高级数值。请以策划后续确认的平衡表为准。

特别注意：策划规定近战接触伤害 10，而角色生命上限也是 10，因此满血被 Monster3 / 5 接触会直接死亡。这是当前按案实现的数值，不是无敌或血条失效。修改近战怪物的 `meleeDamage` 或玩家 `maxHp` 即可调整。
