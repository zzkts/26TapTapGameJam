# 三章回流：播种与涌现

2026-10-15，本轮只更新 Unity 项目，不生成新的安装包。

## 通关流程

| 章节 | 环境与目标 | 下一步 |
|---|---|---|
| 第一章：雨后泵站 / GameScene | 左侧蓄压、右侧重量、高处导电，任选两座节点接通 | 回中央出口，E 打开章末界面，再进入菌林 |
| 第二章：共生菌林 / SporeScene | 母菌生长、火毒连锁、菌冠导电，任选两座节点接通 | 回中央出口，E 进入核心 |
| 第三章：净化核心 / CoreScene | 接通任意两座核心节点，唤醒三名守卫 | 击败守卫后回中央阀门，E 阅读最终记录并选择结局，完成胜利 |

每章是一张约 40 米宽的中央集合、左右支路与高处回环地图。出口始终可穿行；目标未完成时 E 会打开地图帮助定位目标。世界边界使用可见洞壁，单向平台从下方和侧面通过，S+空格下落。

右上方持续显示章节及胜利条件，中上方显示目标方向、距离和方法。M 打开可点击的目标地图：点击一座节点设置导航。达到章末条件后默认导航中央出口，仍可选择第三座节点继续拿额外样本。

## 主角的新玩法

主角可以把材料带到需要的位置：Q 轮换水种、火种、孢子种；R 在瞄准位置播种，最大距离 3.3 米；T 回收自己的种子。最多同时维持两枚，第三枚会替换最早的种子。种子持续 25 秒，使用回流能量，能量自动恢复，附近反应也返还能量。

种子是真实的可移动刚体，与场景使用同一套材料反应。

| 组合或操作 | 场景结果与用途 |
|---|---|
| 水种 + 火种 | 蒸汽可抬起人物、箱体和种子，帮助登高 |
| 孢子种 + 火种 | 范围连锁爆破，可击破菌壳并伤害周围敌人 |
| 水种 + 环境电源 | 水渍与湿润材料桥接导电；湿润人物也可能成为电路的一部分 |
| 水种 + 活体母菌 | 生长并释放影响邻居的孢子 |
| 种子、箱体或人物 + 阀板 | 同一套质量规则触发重量节点 |
| F / S+F | 推流 / 吸回湿润材料，并搬运附近已有水场 |

这使玩家能够自己安排材料、位置和反应顺序。基因继续改变武器和附魔，节点奖励与支路冷库扩展构筑；Monster4 治疗者仍参与各章遭遇。

移动同时加入一次空中泡泡踏跃和瞄准方向的八向冲刺。空中再次按空格踏跃，落地恢复；踏跃消耗少量回流能量。Shift 冲刺速度为 8.5 米/秒。离台起跳宽限和落地跳跃缓冲均为 0.22 秒，原有短跳、长跳、受伤无敌和平台下落继续生效。

## 问题修正

- 原先横在路径上的核心锁随旧长地图移除，三章出口全部使用触发碰撞体，没有实体门柱。
- 压板留出足够的地面空间，避免被上方平台托起而无法触发。
- 单向平台侧面不形成拦截，落地检测忽略人物脚底上方的平台，避免把平台侧面误判成地面。
- 平台下方播种与推流遵守单向平台的穿透规则；实体墙仍阻挡播种与推流。
- 章节、节点、基因实例、反应发现和结局写入当前场景的存档；第二章死亡重试仍回第二章，已破坏菌壳保持破坏状态。
