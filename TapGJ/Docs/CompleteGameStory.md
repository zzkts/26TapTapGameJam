# 回流纪事：剧情与存档

本章依次经过废弃实验区、菌落生态区和净化核心。地漏从维修日志中的 NODE-03 线索出发，收集水、火、毒与冲刺模块，阅读实验记录后进入核心守卫战。击败三名守卫后，最右侧的回流阀允许玩家选择两个结局：

- **水的归处**：打开回流阀，让地下生命进入城市水路。
- **最后的回声**：启动净化，暂时封存地下世界，并保留最后一颗水滴。

对话支持逐字显示、空格或点击继续、跳过当前段落。跳过核心记录仍然会显示最终选择，不能替玩家选择结局。对话、选择和结果页暂停玩家及关卡；结果页可再次探索或返回主菜单。

检查点位于三座终端附近（x=16、41、78）。存档保留基因实例身份、进化等级、累计数量、六个装配槽的准确位置、冲刺模块、已读记录、已领取的关卡奖励和核心是否被清除。继续游戏与死亡重试回到安全检查点并恢复生命；未完成的核心战重新开始。完成结局后关闭“继续游戏”，另开一局保留已经发现的结局。

## 验证入口

`RunProgressTests` 提供 12 个 Unity EditMode 测试用例，检查存档序列化、两个结局、历史结局保留、无效存档拒绝、时钟和区域修正、文案覆盖、剧情触发器的实体碰撞器，以及剧情 UI 始终使用屏幕 Canvas，避免误挂在世界指示牌或敌人血条上。

在完整 GameScene 的 Play Mode、StorySession.Ready 为真时执行：

```csharp
StoryPlayModeChecks.Run();
```

读取 `StoryPlayModeChecks.Running`、`Succeeded` 和 `Results`。测试使用独立玩家及剧情 UI，验证检查点恢复后的生命、位置、冲刺、基因等级与数量、独立实例、槽位及空槽；再点击真实结局按钮，检查无法跳过选择、对应结局文案、结果页和历史结局。它备份并恢复两个 PlayerPrefs 存档键。验证会关闭当前剧情弹窗，完成后重新加载本次关卡以继续体验。

完整世界的移动、跳跃、战斗、奖励与出口验证由 `CompleteWorldRunthrough` 完成。这里的剧情验证报告不能替代从主菜单进入、死亡重试、继续游戏和通关的实际场景流程检查。
